# Security policy

## Supported versions

Security fixes go into the latest release. Please upgrade to it before
reporting.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through
[GitHub Security Advisories](https://github.com/piqab/rgstr/security/advisories/new)
or by email to piqabot@gmail.com.

Include the version, how to reproduce the problem and its impact. You will
get an answer within a week; once a fix is released, the advisory is
published with credit to you, unless you prefer otherwise.
